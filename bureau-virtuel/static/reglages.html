في كل خانة: اضغط الزر الأزرق، انسخ ما يظهر لك، ثم الصقه هنا واضغط «حفظ». المكتب يتحقق من كل شيء ويحفظه تلقائياً على حاسوبك فقط.

🧠 1. عقل الوكلاء (Gemini) — مجاني

  1. افتح صفحة المفتاح ثم اضغط Create API key وانسخه.

📱 2. تيليغرام: التقرير وأزرار الموافقة على هاتفك

  1. افتح BotFather ثم اكتب /newbot، واختر اسماً، ثم اسم مستخدم ينتهي بـ bot (مثال: alwasset777_bureau_bot). سيعطيك رمزاً، انسخه.
  3. اضغط (يظهر الزر بعد حفظ الرمز) ثم اضغط Start / ابدأ داخل تيليغرام.

🗂️ 3. قاعدة الموقع (العقارات وطلبات الزبائن)

  1. افتح صفحة «حساب الخدمة» في Firebase واختر مشروع الموقع.
  2. اضغط Generate new private key ثم Generate key، وسيُحمَّل ملف.

⚠️ هذا الملف يفتح قاعدتك بالكامل: لا ترسله لأي أحد. المكتب يحفظه على حاسوبك فقط.

📣 4. فيسبوك وإنستغرام والإشهار (Meta)

هذه أطول خطوة (حوالي 10 دقائق). اتركها للأخير إن أردت؛ باقي المكتب يعمل بدونها.

  1. أنشئ تطبيق Meta واختر Other / أخرى ثم Business، وسمّه «Bureau Al Wasset».
  2. افتح «المستخدمون النظاميون» ثم: Add / إضافة ← الدور Admin ← Assign assets / تعيين أصول: صفحتك، وحساب إنستغرام، وحساب الإشهار، والتطبيق (تحكم كامل).
  3. اضغط Generate new token / إنشاء رمز، واختر التطبيق، وفعّل هذه الصلاحيات (انسخها من هنا للبحث عنها):
    pages_show_list, pages_read_engagement, pages_read_user_content, pages_manage_engagement, pages_messaging, instagram_basic, instagram_manage_comments, ads_management, ads_read, business_management
  5. سقف ميزانية الإشهار في اليوم (لا يمكن للوكيل تجاوزه أبداً):

للرد على الزبائن الحقيقيين في ماسنجر وإنستغرام قد تطلب Meta «توثيق النشاط التجاري» (مجاني، يأخذ بضعة أيام): صفحة التوثيق
