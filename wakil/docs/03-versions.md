# 03 – Fonctionnalités MVP, V1, V2, V3

## MVP — livré (cette version)
- Onboarding (prénom, clé gratuite testée, projet agence, code de verrouillage)
- Chat multi-conversations + mode **Agent autonome** (plan, étapes, outils, contrôle qualité, corrections, réponse finale)
- 10 outils intégrés + 2 outils Mac + plugins HTTP
- 5 agents prêts (Wakil, Développeur, Chercheur, Agent immobilier Al Wasset 777, Rédacteur) + agents personnalisés
- Fichiers (aperçu HTML/MD/CSV/SVG/images, édition, ZIP, PDF), projets, mémoire, historique
- 8 fournisseurs IA, liste des modèles récupérée en direct
- PWA hors-ligne (web, iPhone, Huawei), APK Android, DMG Mac (fabriqués par GitHub Actions)

## V1 (jours 31–60)
- Synchronisation Supabase validée en conditions réelles + résolution de conflits plus fine
- Réponses en streaming (affichage mot à mot)
- Export DOCX/XLSX/PPTX natifs (bibliothèques gratuites)
- Recherche web : plusieurs requêtes en parallèle et déduplication des sources
- Arabe complet pour l’interface
- Tests sur appareils réels (Huawei, iPhone, Mac Intel)

## V2 (jours 61–90)
- **Moteur Mac « ordinateur de l’agent »** : navigateur piloté (Playwright local), Python, conversions de fichiers
- **Télécommande** : tâche lancée depuis le téléphone, exécutée sur le Mac, résultat synchronisé
- Tâches planifiées (chaque matin : rapport, veille annonces…)
- Connecteurs gratuits : Google Drive, Gmail (OAuth), WhatsApp (liens), calendrier
- Notifications (Mac natives, web push sur Android)

## V3 (après 90 jours)
- Multi-agents (un agent chef répartit le travail entre agents spécialisés)
- Équipe : comptes partagés, rôles, projets communs
- Publication App Store / AppGallery (si décidé — compte Apple payant requis pour l’App Store)
- Marketplace de plugins, mode vocal temps réel
