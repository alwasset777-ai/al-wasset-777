# Wakil — agent IA autonome

Application originale d’agent IA autonome (planifie → exécute → vérifie → livre), pour **web/iPhone (PWA)**, **Android/Huawei (APK)** et **Mac (Apple Silicon + Intel)**. 100 % gratuite à utiliser.

- Web : https://wakil-ia.vercel.app
- Téléchargements : https://github.com/alwasset777-ai/al-wasset-777/releases/tag/wakil-latest
- Documentation complète : [`docs/`](docs/00-sommaire.md) (aussi visible dans l’app → Guide)

```bash
cd wakil
npm install
npm run dev      # développement
npm test         # tests unitaires
npm run build    # production
npm run e2e      # test navigateur complet (après build)
```
