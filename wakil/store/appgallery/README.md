## Fiche (FR)
- **Nom** : Wakil — Agent IA autonome
- **Description courte (≤ 80 car.)** : Votre agent IA : il planifie, cherche, crée vos fichiers et vérifie.
- **Description** :
  Wakil est un agent d'intelligence artificielle autonome. Donnez-lui un objectif (un rapport, un site web, une analyse, une présentation) : il le découpe en étapes, cherche les informations sur le web, crée les fichiers, vérifie la qualité et vous livre le résultat.
  • Mode Agent autonome et mode Chat • Conversations multiples • Projets avec consignes • Fichiers exportables (ZIP, PDF) • Mémoire de vos préférences • Historique et recherche • Agents spécialisés (dont un agent immobilier) • Choix du modèle IA (Google Gemini gratuit, Groq, OpenRouter, Mistral, Ollama…) • Mode démonstration sans clé • Thème clair/sombre • Données stockées sur votre téléphone, sans publicité.

## Notes pour l'examinateur Huawei (champ « Test account / remarks »)
> No account is required. On first launch, tap « Pas de clé pour l’instant ? Essayer en mode démonstration » to test the app without any API key (web search and file creation work for real). For full AI answers, a free Google Gemini API key can be created at https://aistudio.google.com/apikey and pasted in Settings → Modèles IA.
