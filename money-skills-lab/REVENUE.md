# REVENUE — Journal des revenus

Règles :
- Une ligne = un encaissement **réel** (pas une promesse, pas un devis).
- Montant en chiffres, devise en code (MAD, EUR…). Pas de séparateur de milliers.
- Preuve = chemin vers `proofs/` (facture, reçu de virement, capture) — masquer les données personnelles.
- Fiscalité : tout revenu doit être déclaré (facture au nom de l'agence si l'activité est couverte, sinon autre statut) — à confirmer avec votre comptable.
