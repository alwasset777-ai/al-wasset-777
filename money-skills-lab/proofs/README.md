# Preuves

Nommer chaque fichier : `AAAA-MM-JJ-description.ext` (ex. `2026-11-20-facture-agence-x.pdf`).
Types : factures/reçus, captures de virement, statistiques de vidéos, captures de messages clients (masquer les numéros), visuels avant/après.
Ne jamais mettre de mot de passe, de RIB complet ou de pièce d'identité ici.
